Project Overview :
This project is a Handwritten Digit Recognition Web Application that allows users to:
-Draw a digit (0–9) on a canvas
-Process the image using computer vision techniques
-Predict the digit using a trained deep learning model
-Display the predicted result instantly
-The model is trained on the MNIST dataset using TensorFlow/Keras.

🛠️ Technologies Used
-Python
-Streamlit – Web App Framework
-TensorFlow / Keras – Deep Learning Model
-NumPy & SciPy – Image preprocessing
-Matplotlib – Visualization
-streamlit-drawable-canvas – Drawing input interface
